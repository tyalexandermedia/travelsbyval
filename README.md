# Travels by Val

Official website for Travels by Val, a travel planning and advisory service.

## About this repository

This repository hosts the source for the Travels by Val website. It is built as a static site so it can be served quickly and indexed well by search engines.

## Structure

- `index.html` — main landing page
- `robots.txt` — search engine crawler directives
- `sitemap.xml` — URL list for search engines

## SEO foundations included

- Semantic HTML5 structure
- Descriptive title and meta description tags
- Open Graph and Twitter Card tags for link previews
- JSON-LD structured data (TravelAgency schema)
- Mobile-responsive, fast-loading layout
- robots.txt and sitemap.xml
